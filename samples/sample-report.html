How to rebuild this in Nerdio Manager

  1. Create the profile: Cloud Desktops > Azure Virtual Desktop > Host Pool Profiles, then New profile > FSLogix, and in the FSLogix Profiles storage area select Add. (help centre)
  2. Fill the named fields from the setting map below -- name, version, Cloud Cache, the Entra ID and exclusion checkboxes, and the profile path.
  3. Open FSLogix Registry Options. In All settings you can search a setting by its registry name and type the value; in Advanced you paste lines in the form "ProfileType"=dword:00000003. The paste blocks below are already in that form. (help centre)
  4. Repeat for the Office container if this host has one, and tick Manage App Service settings / Manage Log settings if those blocks are not empty.
  5. Assign it: per host pool under Settings > FSLogix, or as the environment default under System > Settings > Integrations. Per-pool settings only reach newly created or re-imaged hosts. (help centre)
  6. Work through the findings before you call it done -- Group Policy, include lists and App Masking are the three that silently undo the rest.
